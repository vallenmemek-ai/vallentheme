tanpa persetujuan pemilik proyek.

- Seret-untuk-urutkan kartu di library (v0.1 memakai `sort_index` statis).
- Playlist/antrean unduhan di fitur "Dari tautan".
- Dukungan Wayland (layer-shell / ekstensi GNOME).
- Editor video sederhana (potong, warna).
- Profil wallpaper per workspace/desktop virtual.
- Sinkronisasi pengaturan antar mesin (butuh akun — bertentangan dengan "tanpa telemetri").
- Dukungan Wallpaper Engine (format `.pkg`).
